FTP · FTPS · SFTP

File transfers, without leaving the keyboard.

A simple, keyboard-driven TUI client inspired by lazygit. If you live in the terminal and keep switching to a GUI just to move files, this is for you.

go install github.com/MawCeron/lazyftp@latest
Download binary

Connecting over SFTP, then uploading a local file and downloading a remote one.

One client, three protocols.

FTPDefault port 21.
FTPSDefault port 21. Certificates are verified; a self-signed one is refused.
SFTPDefault port 22.

Three keystrokes to move a file.

01

Navigate

Move with j / k or the arrows. Enter opens a directory, - goes up.

02

Mark

Press Space on as many files or directories as you like for a batch transfer.

03

Transfer

Press t. In the local panel it uploads; in the remote panel it downloads.

What you get

✓Multiple file selection and batch transfers

Install

Binary

.deb and .rpm packages and archives for Linux, macOS and Windows, x86-64 and arm64. No Go toolchain needed. For an archive, put lazyftp on your PATH.

go install

go install github.com/MawCeron/lazyftp@latest

From source

git clone https://github.com/MawCeron/lazyftp.git
cd lazyftp && go build -o lazyftp .

Flags

--verboseShow the FTP control dialogue in the Log panel
--log-file <path>Write the log to a file as well
--no-nerd-fontsPlain Unicode symbols instead of Nerd Font icons
--highlight-diffMark files that differ between Local and Remote
-i, --identity <path>SFTP private key to try first
--protocol <ftp|ftps|sftp>Protocol, when the destination has no scheme
--versionPrint the version and exit

Connection failing?

Put the whole exchange in a file you can attach to an issue. Passwords are masked.

lazyftp --verbose --log-file lazyftp.log
